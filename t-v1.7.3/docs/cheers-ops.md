# CASPER 완주자의 한 줄 응원 운영 안내

CASPER는 별도 백엔드 서버 없이 정적 배포(GitHub Pages)로 동작합니다. 완주자가 남긴 한 줄 응원은 **외부 구글 폼으로 수집 → 개발자 검토 → `cheers.json` 반영** 순서로 안전하게 전달됩니다.

---

## 1. 구글 폼 만들기 및 미리 채우기 링크 얻기

1. [Google Forms](https://forms.google.com)에서 새 설문지를 만듭니다.
   - 제목 예시: `CASPER 완주자의 한 줄 응원`
   - 설명 예시: `이름이나 연락처는 적지 말아 주세요. 검토 후 익명으로 다른 사람의 공방에 전해집니다.`
2. **질문은 1개만** 만듭니다.
   - 질문 유형: **단답형**
   - 질문 제목: `다음에 걸어올 누군가에게 남길 한 줄 (최대 60자)`
   - 필수 항목으로 설정하고, 설정 탭에서 **이메일 수집 안 함**·**로그인 필요 해제**로 익명 제출을 보장합니다.
3. 우측 상단 메뉴(`⋮`) → **미리 채워진 링크 가져오기**를 클릭합니다.
4. 단답형 입력칸에 임시 텍스트(`TEST`)를 입력한 뒤 **링크 받기 → 링크 복사**를 누릅니다.
5. 복사된 링크는 다음과 같은 형태입니다:
   ```text
   https://docs.google.com/forms/d/e/1FAIpQLSe.../viewform?usp=pp_url&entry.123456789=TEST
   ```
6. 맨 끝의 `TEST`만 지우고 `=`까지 남긴 문자열을 `t-v1.7/cheers-engine.js` 상단의 `CHEERS_SUBMIT_URL` 상수에 넣습니다:
   ```js
   const CHEERS_SUBMIT_URL = 'https://docs.google.com/forms/d/e/1FAIpQLSe.../viewform?usp=pp_url&entry.123456789=';
   ```
   - `CHEERS_SUBMIT_URL`이 빈 문자열(`''`)이면 앱에서 외부 제출 버튼은 자동으로 숨겨지고 로컬 저장("내가 남긴 한 줄")만 동작합니다.
   - 앱은 사용자가 입력한 문장 외에 누적 시간, 기기 정보 등 어떤 개인 정보도 폼 URL에 포함하지 않습니다.

## 2. 응답 시트 검토 기준

구글 폼 **응답 → 스프레드시트 연결**로 응답 시트를 열어 검토합니다.

### 제외 대상 (공개 불가)
- **자해·자살·폭력 암시** 또는 타인·자신에 대한 혐오·비하 표현
- **개인 정보:** 실명, 닉네임 홍보, 전화번호, 이메일, SNS 아이디, 특정 학교·회사·지역 식별 정보
- **광고·외부 링크:** URL, 서비스/상품 홍보, 스팸 문구
- **비교·죄책감 유발:** 순위, 경쟁, 훈계조("남들은 벌써", "게으르면 안 돼" 등)

### 유지 원칙
- **맞춤법·띄어쓰기·말투는 고치지 않습니다.** 완주자 본인의 온기와 말투를 그대로 보존합니다.
- 60자를 넘는 문장은 검토 단계에서 제외하거나, 폼 응답 검증(길이 제한 60자)을 걸어 두면 편리합니다.

## 3. `cheers.json` 반영 및 배포 순서

1. 검토를 통과한 문장을 `t-v1.7/cheers.json`의 `messages` 배열에 추가합니다.
   - `id`는 중복되지 않게 순차 부여합니다 (`"c004"`, `"c005"`, ...).
   - 실제 완주자 문장이 충분히 쌓이면 `"sample": true`가 붙은 초기 예시 3개는 그대로 두거나 필요 시 제거해도 됩니다.
   ```json
   {
     "version": 1,
     "messages": [
       { "id": "c001", "text": "오늘 겨우 5분만 앉았더라도, 그 5분은 절대 사라지지 않아요.", "sample": true },
       { "id": "c004", "text": "검토를 통과한 실제 완주자의 한 줄" }
     ]
   }
   ```
2. JSON 문법 오류 여부와 단위 테스트를 확인합니다:
   ```bash
   /System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc tests/timer-core.test.js
   ```
3. GitHub Pages에 커밋·푸시합니다.
   - `sw.js`는 `cheers.json`을 **네트워크 우선(`network-first`)**으로 처리하므로, 온라인 사용자는 별도 앱 버전업 없이도 새 문장을 바로 받아볼 수 있고 오프라인에서는 마지막 캐시 본문을 사용합니다.
